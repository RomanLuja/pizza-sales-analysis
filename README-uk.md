# Аналіз продажів піцерії

Проміжний проєкт курсу *Data Analytics & Engineering* · Автор: Roman Luja · 06.10.2026 · [Deutsche Version](README-de.md) · [English version](README-en.md)

## Завдання

Нова власниця піцерії в Нью-Джерсі, Лаура Мартінес, отримала разом із закладом вивантаження з каси за весь 2015 рік. Їй треба ухвалити три рішення: скласти графік змін, вибрати піци для вилучення з меню та обрати час і тип акції. Датасет — 4 таблиці з Kaggle (*Pizza Place Sales*). Потрібно відповісти на 8 ключових питань, побудувати інтерактивний дашборд і дати рекомендації з цифрами.

## Дані

- Таблиці: `orders` (21 350 рядків), `order_details` (48 620), `pizzas` (96), `pizza_types` (32). Опис полів: [docs/data_dictionary.md](docs/data_dictionary.md).
- Період: 01.01.2015–31.12.2015 (замовлення є в 358 днях).
- Якість даних: 0 пропусків, 0 дублікатів ключів, 0 «осиротілих» зв'язків, 0 замовлень без позицій. Виручка = ціна × кількість; `JOIN` усіх таблиць у `sales_lines` дає ті самі 48 620 рядків без втрат.
- Проблеми з цілими числами в SQLite (ділення дає ціле): усі частки й середні рахуються через `1.0 *` або `CAST ... AS REAL`.

## Ключові питання та відповіді

1. Загальні показники → виручка \$817 860, 21 350 замовлень, 49 574 піци, середній чек \$38.31, 2.3 піци в замовленні → [sql/queries-uk.sql](sql/queries-uk.sql), Q1
2. Динаміка по місяцях → найсильніший липень (\$72 557.9), найслабший жовтень (\$64 027.6), різниця 13.3% → Q2
3. Дні тижня та години → максимум у п'ятницю (70.8 замовлень на день), мінімум у неділю (50.5); піки 12–13 та 17–18 (45.5% замовлень), тихо о 14–15 → Q3
4. Бестселери й аутсайдери → за виручкою Thai Chicken (\$43 434), за кількістю Classic Deluxe (2 453 шт.); найслабша Brie Carre (\$11 588.5; 490 шт.) → Q4
5. Категорії та розміри → категорії майже рівні (Classic 26.9%, Supreme 25.5%, Chicken 24.0%, Veggie 23.7%); розмір L дає 45.9% виручки, XL+XXL лише 1.8% → Q5
6. Кандидати на вилучення → Brie Carre, Green Garden, Spinach Supreme, Mediterranean: разом \$56 182.5, 6.87% виручки → Q6
7. Великі замовлення → замовлення від 4 піц: 18.2% замовлень, 39.4% виручки, середній чек \$83.1 проти \$28.4 → Q7
8. Акція → вікно Пн–Ср 14:00–16:00: 1 172 замовлення, \$45 550.3 виручки, +10% = +\$4 555 на рік (до вартості знижки) → Q8

## Інструменти

SQL (SQLite) для відповідей на питання, Tableau Public для інтерактивного дашборду (фільтри за розміром, категорією та місяцем), HTML/PDF для презентації.

## Рекомендації для бізнесу

- **Графік змін:** повний персонал:
  - Пн–Чт: 12:00–14:00, 17:00–19:00
  - Пт: 12:00–14:00, 17:00–21:00
  - Сб: 17:00–21:00
  - Нд: 17:00–19:00

  В інший час достатньо мінімального складу.
- **Меню:** 6 тижнів тесту без Brie Carre, Green Garden, Spinach Supreme і Mediterranean (6.9% виручки). Якщо виручка не постраждає, прибрати остаточно; якщо гості масово йдуть, переглянути рішення.
- **Акція:** у Пн–Ср з 14:00 до 16:00 піци Classic розміру L (найсильніша категорія й розмір), для груп від 4 піц — набір із бонусом. Перевірити тестом 6 тижнів.

## Обмеження і наступні кроки

- Дані лише за один рік (2015) і лише з каси: немає витрат і зарплат, тож аналізується виручка, а не прибуток.
- Ознаки «компанія» в даних немає, тому припущення про корпоративних клієнтів перевірити неможливо.
- Ефект акції та вилучення піц — оцінка. Наступний крок: 6-тижневий тест акції та меню з порівнянням виручки.
